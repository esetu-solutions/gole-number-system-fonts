Computing

Gole changes how many glyphs a computer lays out and draws. For your number above, Gole needs this much of what decimal needs:

The dashed line is decimal at 100%. Shorter bars mean less work.

Half the glyphs to shape and draw

Text layout, font lookup and rasterising scale with the number of glyphs. Every million 10-digit numbers on screen is 5 million glyphs instead of 10 million.

Fewer lit pixels6

On OLED screens each pixel makes its own light, so display power depends on how many pixels are lit and how bright they are. In dark mode, light Gole numbers light fewer pixels; the Pixels drawn bar shows how many. The saving applies to the number text only, not the whole screen.

More data per screen

Narrower columns fit more values per row on dashboards, phones and smartwatches, which means less scrolling and fewer pages to render.

Storage depends on the font build7

With the Ligature build, the text stays ordinary digits, so it costs the same bytes as decimal plus at most one padding 0 per number. The PUA build stores each pair as one Private Use Area character8, 3 bytes in UTF-8 against 2 for the two digits it replaces. With the PUA build, store and compute with the decimal value and convert to Gole only for display.

Change any value and the paper figures update.

Global average for an 80 g/m² A4 sheet; varies with the wood source2
UK Government factor for primary paper and board ≈ 1.283; mill declarations go as low as 0.094, full life cycle above 3

Measurements. Symbols counts digits against Gole glyphs; separators such as ., / and : stay the same and are not counted. Width and ink come from drawing both versions on a canvas at the same font size, decimal in your system's sans-serif font, so they vary a little by device. Ink is pixel coverage, a stand-in for printed ink (toner yield is rated by page coverage5) and for lit pixels on screen. Bytes are counted with the browser's own UTF-8 encoder7.

How the conversion works

Pad the whole part on the left and the fraction on the right to an even length, and display the digits as they are. The Ligature build of GoleStandard, used on this page, draws each pair of digits as one Gole symbol. With the PUA build, turn each pair n into the character U+E441 + n instead.

// Ligature build: the padded digits are the Gole text.
const toGole = (v) => {
  const [int, ...rest] = String(v).replace(/[^\d.]/g, "").split(".");
  const frac = rest.join(""), i = int || "0";
  return (i.length % 2 ? "0" + i : i) +
    (rest.length ? "." + (frac.length % 2 ? frac + "0" : frac) : "");
};

// PUA build: one character per pair, U+E441 + n.
const toGolePUA = (v) =>
  toGole(v).replace(/\d\d/g, (p) => String.fromCharCode(0xE441 + Number(p)));

toGole(1234567); // "01234567" shows [01][23][45][67]
toGole(12.5);    // "12.50"    shows [12].[50]
Sources

Symbols, width, pixels and bytes are measured on this page. The figures below are the published factors behind the paper, toner and computing notes.

  1. Trees. Conservatree, “So how many trees would make a ton of paper?”: about 24 trees per US ton of uncoated virgin office paper. conservatree.org
  2. Water. A. Y. Hoekstra, Water Footprint Network, global average water footprints: 10 L of water per 80 g/m² A4 sheet. Hoekstra (2010), The Environmentalist
  3. CO₂e. UK Department for Energy Security and Net Zero, Government greenhouse gas conversion factors for company reporting, material use: mixed paper and board, primary material production, about 1,283 kg CO₂e per tonne. gov.uk
  4. CO₂e, low end. Holmen, paper climate impact: about 90 kg CO₂e per tonne, cradle to gate, for an 80 g/m² paper from a mill with low-carbon energy. holmen.com
  5. Toner. ISO/IEC 19752:2025, method for determining toner cartridge yield, which rates yield against a test page of fixed coverage. iso.org
  6. OLED power. M. Dong, Y.-S. K. Choi and L. Zhong, “Power modeling of graphical user interfaces on OLED displays”, Design Automation Conference 2009. OLED power depends on the colour and intensity of each pixel; the relationship is not linear. Summary (UCL)
  7. UTF-8. RFC 3629: characters U+0800 to U+FFFF, which include the PUA build's U+E441–U+E4A4, take three bytes. rfc-editor.org
